ABSTRACT


The technology industry is evolving at an unprecedented pace, creating a significant gap between the skills that job seekers possess and the skills that employers require. Fresh graduates and early-career professionals often struggle to identify exactly what they need to learn for their target job roles, lacking a systematic way to analyse their skill gaps and generate personalised learning plans.

This project presents the design and implementation of an AI-Powered Skill Gap Generator and Personalized Learning Path Recommender — a full-stack web application that helps users identify skill gaps between their current abilities and their target job roles, and generates day-by-day personalised learning roadmaps to bridge those gaps. The system accepts user skills through manual entry or PDF résumé upload, analyses GitHub profiles for coding quality indicators, identifies missing skills using web-augmented AI, generates time-constrained learning paths with curated resources and portfolio projects, and aggregates real job listings from multiple APIs with experience-level filtering and location-aware ranking.

The application is built using React.js with Vite and Framer Motion for the frontend, Python Flask for the backend, Supabase for database and authentication, and Groq API for fast LLM inference. Key innovations include a hybrid AI-plus-keyword résumé parsing system, a fresher-friendly GitHub scoring model, a background pre-fetch architecture for sub-10-second learning path generation, and parallel multi-source job aggregation with location-aware ranking for the Indian job market.


Keywords: Skill Gap Analysis, Personalized Learning, AI-Powered Recommendations, Resume Parsing, Job Aggregation, Retrieval-Augmented Generation (RAG), Flask, React.js, Groq API, Supabase

Chapter 1
INTRODUCTION

1.1 Background and Motivation

The technology industry is evolving at an unprecedented pace. New frameworks, programming languages, tools, and methodologies emerge almost every month. For someone looking to switch careers or level up within the tech industry, the sheer volume of skills to acquire can feel overwhelming. A fresher graduating with a Computer Science degree might know Python and some basic web development, but they often do not know exactly what specific technologies a "Full Stack Developer" or "Data Scientist" role actually requires. Even experienced professionals sometimes struggle to keep up with shifting industry demands.

Traditional learning platforms such as Coursera, Udemy, and LinkedIn Learning offer thousands of courses. However, these platforms suffer from a critical limitation: they take a one-size-fits-all approach. A learner must manually search for relevant courses, guess which technologies are in demand, and figure out the correct sequence in which to learn them. Most learners spend weeks researching before they even start learning, and many give up halfway because they do not have a clear roadmap or visible progress.

The problem becomes even more complex when we consider the Indian job market specifically. With over 50 lakh engineering graduates entering the workforce every year, the competition for entry-level tech jobs is fierce. Freshers often apply to hundreds of jobs without understanding how their existing skills match against what employers actually want. They lack a tool that can objectively compare their current abilities against job requirements and tell them precisely what they need to learn.

Beyond freshers, working professionals also face challenges. Someone working as a backend developer who wants to transition to an ML Engineer role needs to identify the exact skill gaps between their current position and the target role. They need a personalised learning plan that respects their time constraints, work schedule, and learning pace. Generic roadmaps found on blog posts do not account for the individual's existing knowledge, daily time availability, or career goals.

The AI-Powered Skill Gap Generator and Personalized Learning Path Recommender was conceived to address all these issues. The platform takes a holistic view of a user's career development journey.

1.2 Problem Statement

The following specific problems form the core motivation for this project:

  1. Lack of Objective Skill Gap Analysis: Most learners do not have a systematic way to compare their current skills against the requirements of their target job role.
  2. No Personalised Learning Roadmaps: Existing platforms provide generic course recommendations without considering the user's existing knowledge, preferred learning pace, or time commitment.
  3. Disconnect Between Learning and Employment: Learning platforms focus solely on content delivery. They do not help learners understand whether their learning efforts will translate into actual job opportunities.
  4. Résumé Blind Spots: Many freshers and early-career professionals do not know how to effectively present their skills. Even when they upload a résumé to existing tools, the extraction is often incomplete or inaccurate.
  5. GitHub Profile Underutilisation: GitHub repositories are a goldmine of evidence for a developer's coding ability, but most tools do not know how to objectively evaluate a GitHub profile without penalising freshers.
  6. Limited Job Discovery for Freshers: Popular job aggregation platforms do not filter jobs by experience level effectively, resulting in freshers seeing senior-level postings.

1.3 Objectives

The project was designed with the following five primary objectives:

Objective 1: To develop a hybrid résumé parsing system that uses both AI (Groq LLM) and keyword-based extraction to identify a user's skills, education, experience, and certifications from a PDF résumé, with automatic fallback mechanisms.

Objective 2: To implement a GitHub profile analyser that evaluates a user's public repositories for quality indicators such as test coverage, CI/CD implementation, and language diversity, generating a fresher-friendly score.

Objective 3: To build a skill gap analysis engine that compares a user's current skills against the required skills for a self-selected target job role, using web-search-augmented AI with a clear match score.

Objective 4: To create an AI-powered learning path generator that produces a day-by-day personalised roadmap for each selected missing skill, including curated resources, YouTube tutorial embeds, and portfolio project recommendations.

Objective 5: To integrate a multi-source job aggregation system that fetches real job listings from Remotive, Jooble, and Adzuna APIs in parallel, filtered by experience level and ranked by location proximity.

1.4 Scope of the Project

Frontend Scope: The React.js frontend implements a six-step interactive wizard. The interface uses a glassmorphism dark theme with Framer Motion animations. A persistent AI chat sidebar provides contextual help at every stage.

Backend Scope: The Python Flask backend exposes REST API endpoints for résumé upload, GitHub analysis, role-based gap analysis, learning path generation, and job search aggregation. JWT-based authentication ensures data privacy and security.

Integration Scope: The system integrates with five external services: Groq API, GitHub REST API, Remotive API, Jooble API, and Adzuna API.

Deployment Scope: Frontend deployed on Vercel; backend deployed on Render. Docker and Docker Compose configuration files are provided for containerised local development.

Out of Scope: Native mobile application, LinkedIn API integration, real-time collaboration, payment processing.

Chapter 2
LITERATURE REVIEW

2.1 Introduction

The development of intelligent systems for career guidance, skill assessment, and personalised learning has been an active area of research for over two decades. This chapter reviews the key areas of related work: skill gap analysis methodologies, personalised learning path generation, NLP-based résumé parsing, GitHub-based developer profiling, and job-skill matching algorithms.

2.2 Skill Gap Analysis in Technology Careers

Chen et al. (2019) proposed SkillNet, an ontology-based framework for technology skill gap analysis. Their approach relied on manual skill taxonomy curation, which became outdated quickly as new technologies emerged. Patel and Kumar (2023) introduced GapScore, a machine learning approach using NLP to extract required skills from job postings. Their system achieved 78% accuracy but was limited by dependence on structured job posting formats.

What distinguishes the current project is the hybrid AI-and-web-search methodology. Rather than relying on a static skill ontology, the system uses the Groq LLM to perform gap analysis augmented by live web search results, ensuring the analysis reflects the latest market demands.

2.3 Personalised Learning Path Generation

Lee and Park (2020) developed AdaptivePath, an algorithm using learner behaviour data from MOOC platforms. Their approach required extensive historical data about the learner, making it unsuitable for new users. Krishnan and Nair (2022) proposed a constraint-based learning path generator considering available time per day, preferred learning style, and target completion date. However, their approach treated all skills as equal-weight and did not consider prerequisite relationships between technologies.

This project advances personalised learning path generation: it generates skill-specific roadmaps for each selected skill, uses Retrieval-Augmented Generation (RAG) with live web search for current resources, and a background pre-fetch architecture ensures generation in 5–8 seconds.

2.4 NLP-Based Résumé Parsing

Sharma and Gupta (2018) found that rule-based extraction achieved ~65% accuracy on standard fields but dropped below 40% for complex fields like skills. Gupta and Mehta (2021) introduced ResumeML, a transformer-based model achieving 87% F1-score on skill extraction for Indian tech résumés. However, the model experienced sharp performance degradation on non-standard layouts.

The hybrid approach in this project uses Groq LLM with carefully engineered prompts for any résumé format, with a fallback vocabulary-based keyword matcher scanning against a curated list of over 500 technical skill terms.

2.5 GitHub-Based Developer Profiling

Das and Bhattacharya (2020) proposed DevScore, which heavily weighted popularity metrics (stars, forks), inadvertently disadvantaging fresh graduates. Kumar and Singh (2023) introduced quality-weighted formula but still relied on aggregate statistics.

This project introduces a "fresher-friendly scoring model" that evaluates quality indicators a fresher can realistically achieve: test coverage, CI/CD presence, type-safety files, and basic star count, starting with a base of 30 points for any repository.

2.6 Job-Skill Matching and Aggregation

Aggarwal and Sharma (2019) introduced SkillMatch, a semantic matching system using word embeddings improving match accuracy by 23%. Reddy et al. (2024) studied the Indian tech job market and found that over 60% of entry-level job listings on major portals targeted candidates with 2–5 years of experience.

The current project queries three independent job APIs in parallel using ThreadPoolExecutor and implements skill-intersection scoring with location-matching for Indian metro city clusters.

3.5 Use Case Descriptions

UC-01: Fresher Uploads Résumé and Discovers Skill Gaps

Actor: Fresher (final-year engineering student) | Precondition: Has a PDF résumé and a GitHub account.

  1. The fresher logs in and lands on the Dashboard at Step 1.
  2. Uploads their PDF résumé; the system parses and extracts skills.
  3. Optionally enters GitHub username; system analyses repositories.
  4. Enters "Full Stack Developer" as their target role.
  5. System displays missing skills with a match score (e.g., 29%).
  6. The fresher selects the skills they want to learn (e.g., React, Node.js, Docker).
  7. Sets preferences: 1 hour/day, Balanced pace, 3-month duration.
  8. System generates a 90-day learning roadmap in ~6 seconds.
  9. System fetches and displays entry-level job listings filtered for freshers.
  10. The fresher saves the path and begins following the daily schedule.

UC-02: Experienced Professional Identifies Career Transition Path

Actor: Software Engineer with 3 years of backend development experience.

  1. Logs in and views their saved skill profile.
  2. Selects "Machine Learning Engineer" as the new target role.
  3. System identifies missing skills: TensorFlow, PyTorch, Statistics.
  4. Professional selects Python, TensorFlow, and Model Deployment.
  5. Sets preferences: 2 hours/day, Fast pace, 2-month duration.
  6. System generates an intensive 60-day roadmap with projects.
  7. System fetches senior-level ML Engineer job listings with location matching.

5.2 Key Algorithm Implementations

Algorithm 1: Hybrid Résumé Skill Extraction

The hybrid extraction pipeline operates in multiple layers to maximise accuracy across different résumé formats:

  1. Text Extraction using pdfminer.six — handles multi-column and complex layouts
  2. AI Extraction via Groq LLM with structured JSON-extraction prompt
  3. Keyword Fallback using a vocabulary of 500+ tech terms organised by category
  4. Context Detection — classifies résumé as "fresher", "experienced", or "neutral"
  5. Field Extraction using regex for Indian cities, dates, URLs, and contact information
  6. Result Assembly — computes filled_percentage as a quality metric (0–100%)

Algorithm 2: GitHub Fresher-Friendly Scoring

score = 30 # Base for having ≥1 repo + min((repos - 1) × 5, 20) # Additional repo bonus (max +20) + (10 if has_tests else 0) # Tests folder bonus + (10 if has_devops else 0) # Dockerfile/.github bonus + (5 if has_types else 0) # Type-safety files bonus + (5 if any_repo_stars_over_5 else 0) # Star bonus + (10 if 3+_languages else 0) # Diversity bonus = CLAMP(result, 0, 100) # Hard cap at 100

Algorithm 3: Fast Learning Path Generation with RAG

The background pre-fetch architecture reduces perceived latency from 40+ seconds to 5–8 seconds:

  • Background (daemon threads): DuckDuckGo searches run immediately when user opens Step 4
  • Foreground: When user submits Step 4, LLM fires using cached search results
  • MD5 Cache: Key = MD5(skill + role + days + hours + pace) — identical requests served instantly
  • Fallback: Structured 3-phase plan (Foundations → Intermediate → Advanced) if AI fails

Algorithm 4: Location-Aware Job Matching

DELHI_NCR = ["delhi", "new delhi", "gurgaon", "gurugram", "noida", "faridabad"] BANGALORE = ["bangalore", "bengaluru", "mysore", "hubli"] CHENNAI = ["chennai", "madras", "coimbatore", "trichy"] skill_score = min(95, 30 + len(matched_skills) × 15) final_score = skill_score + (30 if is_nearby else 0) + (15 if is_remote else 0)

7.5 Limitations

  1. GitHub API Rate Limits: 5,000 requests/hour even for authenticated requests; high-volume usage may hit limits.
  2. AI Response Variability: Non-deterministic LLM responses can produce slightly different roadmaps for identical inputs on repeat generation.
  3. Free-Tier Job API Constraints: Jooble and Adzuna free tiers have limited query volumes and partial data coverage for niche roles.
  4. PDF Parsing Limitations: Image-based (scanned) PDFs with no extractable text layer cannot be parsed by pdfminer.six.
  5. Mobile Chat Sidebar: The persistent AI chat sidebar occupies 30% of screen width on mobile, reducing the wizard panel space.
  6. No LinkedIn Integration: Users cannot import professional history directly from LinkedIn at this time.
